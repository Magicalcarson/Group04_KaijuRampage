# Kaiju Rampage: โค้ดลงบอร์ด Nexys A7-100T (Group04, CPE222)

เกมครบทุก feature ตามสไลด์ของกลุ่ม ใช้ Vivado 2024.2

| Feature | ทำแล้วในโค้ดนี้ |
|---|---|
| **1 · Movable Player** | ควบคุมแบบ real-time, เดิน 4 ทิศ, กระโดดและตกตามแรงโน้มถ่วง, กล้องเลื่อนตามบนแมพ 128×96 ช่อง, ไม่หลุดขอบแมพ, ชนสิ่งกีดขวาง/ไอเท็ม/ศัตรู |
| **2 · Sprite Evolution** | เบบี๋ไคจู → (กินต้นไม้ 20 ต้น) → ไคจูวัยรุ่น → (คะแนน 1500) → ไคจูเต็มวัย แต่ละร่างทำลายของได้ต่างกัน เร็วต่างกัน HP ต่างกัน |
| **3.1 · ระบบ Tile** | แมพเก็บเป็นเลขช่อง 4 บิต + รูป tile 16 แบบ ใช้ความจำ ~168 Kbit แทน 2,760 Kbit |
| **3.2 · Sound effect + เพลง** | เสียงกิน, กระโดด, พัง, stomp, โดนยิง, เก็บของ, คำราม, เริ่มเกม/วิวัฒนาการ/ชนะ, แพ้ และเพลงประกอบวนระหว่างเล่น (เปิดด้วย SW15) |
| **3.3 · Score, HP, Time บน 7-Segment** | `SCORE` 4 หลัก, `HP` 1 หลัก, `TIME` 3 หลัก จุดหลัง HP = มีโล่ จุดหลังสุด = รองเท้าเร่งความเร็ว |
| **3.4 · ศัตรูเพิ่มตามร่าง** | รถตำรวจ (ยิงตรง), รถถัง (กระสุนแรง 2), เฮลิคอปเตอร์ (บินข้ามตึก ยิง 3 ทาง), รถขนระเบิดนิวเคลียร์ (พุ่งชนแล้วระเบิด แรง 2) จำนวนสูงสุด 4 / 8 / 8 คันตามร่าง (เกิดทุก ~1.7 / 1.2 / 0.9 วิ) |
| **3.5 · Power-ups** | ฮีล (HP + 1), รองเท้า (เร็วขึ้น 10 วิ), โล่ (กันดาเมจ 1 ครั้ง) โผล่บนพื้นทุก ~15 วิ |
| **3.6 · เมืองพังได้จริง** | กินต้นไม้/รถ, บ้านกลายเป็นไฟ, ตึก 2×2 พังทั้งหลัง, ไฟดับเองกลายเป็นซาก, stomp ของร่าง 3, เริ่มใหม่แล้วเมืองกลับมา |
| **3.7 · แหกปากใส่ไมค์ → คำราม** | ตะโกนใส่ไมค์บนบอร์ด → ศัตรูในรัศมี 128 px นิ่ง 2 วิ และกระสุนรอบตัวหายไป พักเสียง 5 วิ (LED17 ฟ้า = พร้อม, แดง = พัก) |

## เวอร์ชัน DEMO (Progress Presentation 20 Nov)

ไฟล์ `bit/kaiju_top.bit` ที่ให้มาเป็นเกมเต็ม (ส่ง 27 Nov) ส่วนเวอร์ชัน DEMO ที่ใช้ตอน Progress Presentation มาจากโค้ดชุดเดียวกัน ต่างกันที่พารามิเตอร์ `DEMO` ใน `kaiju_top.v` (`DEMO = 1` ปิดร่าง 3, ศัตรู, HP, Power-ups, เสียง และไมค์) ใน DEMO สวิตช์ `SW1 SW0 = 11` จะได้ร่าง 2 สร้างและโหลดลงบอร์ดได้ด้วย

```
C:\Xilinx\Vivado\2024.2\bin\vivado.bat -mode batch -source build.tcl -tclargs demo
C:\Xilinx\Vivado\2024.2\bin\vivado.bat -mode batch -source program.tcl -tclargs demo
```
(ไม่ใส่ `-tclargs demo` = เกมเต็ม)

## วิธีเล่นบนบอร์ด

| อุปกรณ์ | หน้าที่ |
|---|---|
| BTNU / BTND / BTNL / BTNR | เดิน |
| BTNC | หน้า Title: เริ่มเกม · ในเกม: กระโดด (ร่าง 3 ตกลงมาแล้ว **stomp**) · จบเกม: กลับหน้า Title |
| CPU RESET | เริ่มใหม่ เมืองกลับมาเหมือนเดิม |
| ไมโครโฟนบนบอร์ด | ตะโกน → คำราม |
| SW1 SW0 | โหมดทดสอบ: `00` ปกติ, `01` / `10` / `11` บังคับร่าง 1 / 2 / 3 |
| SW13 SW12 | ความไวไมค์: `00` ปกติ, `01` ไวมาก, `10` ต้องดังขึ้น, `11` ต้องดังมาก |
| SW14 | LED15–0 แสดงระดับเสียงไมค์ (ใช้ปรับความไว) |
| SW15 | เปิดเสียง (ต่อหูฟังหรือลำโพงที่ช่อง audio) |
| จอ VGA | 640×480 @ 60 Hz (ภาพเกม 320×240 ขยาย 2 เท่า) |
| 7-segment | `SCORE` · `HP` · `TIME` (หน้า Title แสดง `---- ---`) |
| LED15–0 | ความคืบหน้าสู่เป้าถัดไป: ต้นไม้ (ร่าง 1) → คะแนน (ร่าง 2) → พังเมือง (ร่าง 3) |
| LED16 | สีของร่าง: เขียว / เหลือง / แดง กะพริบตอนวิวัฒนาการ |
| LED17 | คำราม: ฟ้า = พร้อม, แดง = กำลังพัก |

**กติกา:**
- **ร่าง 1 เบบี๋ไคจู:** HP 3, เดิน 2 px/เฟรม กินได้แค่ต้นไม้ (+5) ชนรถ บ้าน ตึก และน้ำ ทำลายศัตรูไม่ได้ (โดนรถชนเสีย HP)
- **ร่าง 2 ไคจูวัยรุ่น:** HP 6, เดิน 1.5 px/เฟรม กินรถ (+20) พังบ้าน (+30) กินรถตำรวจ/รถถังที่ชน (+50)
- **ร่าง 3 ไคจูเต็มวัย:** HP 9, เดิน 1 px/เฟรม พังตึก (+100) ลุยน้ำได้ กระโดดลงมา stomp พังรอบตัวและระเบิดศัตรูใกล้ๆ
- **ศัตรู:** กระสุนวิ่งชนบ้าน/ตึกแล้วหาย ถ้ากระโดดสูงพอ (เกิน 4 px) กระสุนและรถจะลอดใต้ตัว
- **โดนโจมตี:** HP ลด แล้วอมตะ 1.5 วิ (ตัวกะพริบ) ถ้ามีโล่ โล่รับแทนครั้งเดียว
- **ชนะ:** พังเมืองครบ 600 ช่อง (ประมาณ 25% ของอาคาร) หรือคะแนนถึง 9999 ขึ้น `YOU WIN!` / `CITY CLEARED` · **แพ้:** HP หมดหรือเวลาหมด ขึ้น `YOU LOSE`
- เวลาเล่น 240 วินาที

## เปิดโปรเจกต์ใน Vivado 2024.2

1. ปิดหน้าต่าง Vivado เดิมก่อน (ถ้าเปิดอยู่) เพราะโปรเจกต์ต้องสร้างใหม่ให้มีไฟล์ใหม่ครบ
2. เปิด Vivado แล้วไปที่ Tcl Console พิมพ์ (ใช้ `/` ไม่ใช่ `\`):
   ```
   cd <โฟลเดอร์ที่ clone มา>/kaiju_fpga
   source create_kaiju.tcl
   ```
3. กด **Generate Bitstream** → **Open Hardware Manager → Open Target → Auto Connect → Program Device**

หรือไม่ต้องเปิดหน้าต่าง Vivado (ประมาณ 5 นาที):
```
C:\Xilinx\Vivado\2024.2\bin\vivado.bat -mode batch -source build.tcl
C:\Xilinx\Vivado\2024.2\bin\vivado.bat -mode batch -source program.tcl
```
ใน GUI ถ้าอยากได้ DEMO: Settings → General → Generics/Parameters ใส่ `DEMO=1`

## หลักการทำงานโดยย่อ

- **แผนที่เป็น tile:** เก็บเลขช่อง 128×96 ช่อง ช่องละ 4 บิต กับรูป tile 16 แบบ แทนภาพทั้งแผนที่ 2048×1536 พิกเซล
- **Tile RAM 2 พอร์ต:** พอร์ต B ให้ส่วนวาดภาพอ่าน พอร์ต A ให้ตรรกะเกมอ่าน/เขียน (กิน/พัง = เขียนเลขช่องใหม่)
- **อัปเดตเฟรมละครั้ง** ตอน y = 480: อ่านปุ่ม → เดินทีละ 1 px และตรวจช่องใต้เท้า → กระโดด/ตก → วิวัฒนาการ → ไอเท็ม → ศัตรูทีละคัน → กระสุนทีละลูก → เกิดศัตรูใหม่ → ชนะ/แพ้ → กล้อง → สแกนไฟทั่วแผนที่
- **ศัตรู/กระสุนหลายตัว:** เก็บเป็นช่อง (slot) ตอนวาดภาพ แต่ละพิกเซลเช็คทุกช่องพร้อมกัน แล้วใช้ ROM อ่านสีของช่องแรกที่ทับ
- **ไมค์:** นับบิต 1 ในทุก 256 บิต (0.1 ms) ห่างจาก 128 มาก = เสียงดัง ถ้าดังเกินเกณฑ์ 3 ช่วงติดกัน (~40 ms) = ตะโกน
- **สุ่ม:** LFSR 16 บิต ใช้สุ่มจุดเกิดศัตรู/ไอเท็ม, ชนิดศัตรู, ไฟดับ และจอสั่น
